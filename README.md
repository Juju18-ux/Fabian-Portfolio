# Fabian Owuor — Portfolio

Personal portfolio for Fabian Owuor, a third-year BSc Information Technology student at Meru University of Science and Technology, focused on applied AI, machine learning, data science, and secure systems.

The site brings together my background, education, skills, selected projects, certifications, and contact links.

## Featured projects

- **Maskani Hub** — A Kenyan property listings platform with search and filters, saved homes, alerts, and viewing requests. Built with React, TypeScript, Firebase, and Firestore. [Visit the live project](https://maskani-hub.web.app).
- **PennyWise** — A personal finance app for accounts, M-Pesa and card balances, transactions, budgets, and savings goals. Built with React, TypeScript, and Supabase.

## Site contents

- About and BSc Information Technology education
- Technical and professional skills
- Featured projects
- Certificates available as PDFs under `assets/certificates/`
- Downloadable resume at `assets/Fabian-CV.pdf`
- Contact form that opens a prefilled email draft, plus GitHub, LinkedIn, and email links

## Built with

HTML, CSS, and vanilla JavaScript. The site is responsive and does not require a build step or package installation.

## Run locally

Open `index.html` in a browser. The project can also be served from this folder with any static file server.

## Deploy

Import this repository into a static hosting provider such as Vercel. Use the repository root as the project root; no build command is required.
